\# Plainly.ai



Plainly.ai is a text-only MVP that explains confusing bills, notices, letters, and paperwork in simple English.



\## MVP Scope



\- Paste document text

\- Select document type

\- Optional user question

\- Generate plain-English explanation

\- Show dates, money, action steps, questions, and unclear parts

\- Collect simple feedback



\## Not Included in V1



\- No accounts

\- No PDF upload

\- No document storage

\- No saved history

\- No professional legal, medical, tax, or financial advice
